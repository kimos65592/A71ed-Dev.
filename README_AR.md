# Groq Rig Studio — نسخة GitHub Pages المستقلة

موقع لعرض مجسمات 3D ذات Rig ومعاينة الحركات المضمّنة، وطلب حركة إجرائية جديدة من Groq بوصف عربي.

## النشر على GitHub Pages
1. فك ضغط الملف ZIP.
2. أنشئ مستودعًا جديدًا على GitHub.
3. ارفع الملفات الموجودة داخل هذا المجلد إلى جذر المستودع: `index.html` و`app.js` و`style.css`.
4. افتح **Settings → Pages**.
5. تحت **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)` واضغط Save.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages وافتحه.

## الاستخدام
1. افتح [Groq Console](https://console.groq.com/keys) وأنشئ مفتاح API.
2. افتح موقعك المنشور، والصق المفتاح في إعدادات Groq ثم اضغط **تفعيل المفتاح**.
3. ارفع مجسمًا بصيغة GLB (الأفضل) أو GLTF أو FBX.
4. اكتب وصف الحركة بالعربية واضغط إنشاء الحركة.

## تنبيهات مهمة
- هذه نسخة **واجهة ثابتة فقط**؛ لا تحتاج Node.js أو Render أو سيرفر خاص.
- مفتاح API لا يُكتب في ملفات المشروع ولا يُحفظ في Local Storage؛ يبقى في ذاكرة الصفحة حتى إغلاقها أو تحديثها. ستحتاج إلى إدخاله مجددًا عند فتح الموقع لاحقًا.
- لأن المتصفح يتصل مباشرةً بـ Groq، فإن المفتاح يُرسل من المتصفح إلى Groq. لا تشارك المفتاح ولا تستخدم الموقع على جهاز عام أو غير موثوق. لا تضف المفتاح إلى أي ملف ترفعه إلى GitHub.
- الاتصال المباشر يعتمد على سماح Groq بطلبات المتصفح (CORS). إذا ظهر خطأ CORS، فلن يمكن حلّه من GitHub Pages وحده؛ ستحتاج إلى وسيط خلفي.
- قد تتغير حدود الاستخدام أو أسماء الموديلات المتاحة في حساب Groq.
- يفضّل استخدام ملف `.glb` لأن ملفات `.gltf` قد تعتمد على ملفات خارجية.
- الحركات المُولّدة تقريبية وتعتمد على أسماء العظام واتجاهاتها، وليست تحريكًا احترافيًا أو تصديرًا نهائيًا لملف الأنيميشن.
