# Groq Rig Studio

Arabic-first Three.js rig animation playground powered by the Groq API.

See [README_AR.md](README_AR.md) for setup and deployment instructions in Arabic.

## Security
- Never commit `.env` or API keys.
- For public deployment, set `GROQ_API_KEY` as a secret environment variable in your hosting provider.
- The in-app API-key setting endpoint is intended for local/private use only and is not authenticated in this starter version.
