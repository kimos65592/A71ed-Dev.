# Groq Rig Studio — نسخة عربية أولية

تطبيق محلي يتيح رفع مجسم GLB / GLTF / FBX، ثم وصف حركة بالعربية ليحوّلها Groq إلى keyframes لدوران العظام، ويعرضها Three.js داخل المتصفح.

## المتطلبات
- Node.js 20 أو أحدث.
- مفتاح API من حساب Groq.
- اتصال إنترنت لتحميل مكتبات Three.js من unpkg والاتصال بـ Groq.

## التشغيل على Windows أو macOS أو Linux

1. فك ضغط الملف.
2. افتح Terminal / PowerShell داخل مجلد `groq-rig-studio`.
3. ثبّت الاعتماديات:
   ```bash
   npm install
   ```
4. يمكنك ضبط المفتاح بطريقتين: من حقل «إعدادات Groq API» داخل واجهة الموقع (الأسهل على Acode)، أو عبر متغير البيئة في `.env`. المفتاح الذي تدخله من الواجهة يبقى في ذاكرة السيرفر فقط ويُمسح عند إعادة تشغيله. لا يُكتب داخل ملفات المشروع.\n\nللتشغيل المحلي في Acode، يمكنك تخطي إنشاء `.env` إذا ستدخل المفتاح من الواجهة. إذا أردت استخدام `.env`، انسخ `.env.example` إلى ملف جديد اسمه `.env`.
   - Windows PowerShell:
     ```powershell
     Copy-Item .env.example .env
     ```
   - macOS / Linux:
     ```bash
     cp .env.example .env
     ```
5. افتح `.env` واستبدل `ضع_مفتاح_Groq_هنا` بمفتاحك. لا ترسل المفتاح لأي شخص ولا تضعه في ملفات `public`.
6. شغّل السيرفر:
   ```bash
   npm start
   ```
7. افتح `http://localhost:3000` في المتصفح.

## رفع المشروع على GitHub وتشغيله على الإنترنت

**مهم:** GitHub Pages يستضيف ملفات ثابتة فقط ولا يشغّل Node.js؛ لذلك ارفع الكود إلى GitHub ثم انشر السيرفر على Render أو خدمة Node.js مشابهة.

1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد. لا ترفع ملف `.env` أو مفتاح Groq.
2. في Render اختر **New + → Web Service** ثم اربط مستودع GitHub.
3. اجعل **Build Command** هو `npm install` و**Start Command** هو `npm start`، والبيئة Node.
4. من إعدادات الخدمة → **Environment** أضف `GROQ_API_KEY` بقيمة مفتاح Groq، ثم أعد النشر.
5. افتح رابط Render الذي يعطيك إياه. عند ضبط `GROQ_API_KEY` على Render لن تحتاج إلى إدخال المفتاح داخل الصفحة.

يمكنك بدلًا من ذلك إدخال المفتاح من واجهة الصفحة، لكن نقطة إعداد المفتاح ليست محمية بتسجيل دخول في هذه النسخة؛ **لا تستخدم إدخال المفتاح من الواجهة على موقع عام** لأن أي شخص لديه الرابط قد يغيّر المفتاح أو يمسحه. عند النشر العام استخدم متغير البيئة `GROQ_API_KEY` في إعدادات الاستضافة.

## استخدامه
1. ارفع ملف GLB (الخيار المفضّل) أو GLTF أو FBX.
2. اكتب وصف الحركة بالعربية أو اختر مثالًا جاهزًا.
3. اضغط «أنشئ الحركة بالذكاء الاصطناعي»، ثم شغّل المعاينة.
4. الحركات المضمّنة في الملف تظل متاحة في قسم «الحركات الأصلية».

## حماية المفتاح
- مفتاح Groq لا يظهر في كود المتصفح. إذا أدخلته من واجهة الإعدادات، يحتفظ به السيرفر في الذاكرة فقط حتى إعادة تشغيله. أو يمكن ضبطه في `process.env.GROQ_API_KEY`.
- لا تضع `.env` داخل مجلد `public` ولا ترفعها إلى Git. `.gitignore` يستثنيها.
- يوجد حد أولي للطلبات: 12 طلبًا في الدقيقة لكل عنوان IP.
- واجهة إدخال المفتاح هذه مخصصة للتطوير المحلي: أي شخص يستطيع الوصول إلى السيرفر قد يغيّر المفتاح أو يمسحه. لا تنشر هذا السيرفر على الإنترنت كما هو؛ أضف مصادقة وHTTPS وحدود استخدام ومراقبة للتكلفة.

## حدود النسخة
- Groq ينشئ تعليمات keyframes وليس ملف motion-capture احترافيًا أو أنيميشنًا مولّدًا من فيديو.
- جودة الحركة تعتمد على أسماء العظام، اتجاهاتها، الـ rest pose والـ rig. قد لا ينجح تحريك كل rig آليًا.
- المعاينة تُطبّق دورانًا محليًا للعظام. لا يوجد حتى الآن تصدير الحركة المعدلة إلى FBX/GLB.
- ملفات GLTF التي تعتمد على ملفات خارجية قد لا تُحمّل من اختيار ملف واحد؛ استخدم GLB أو شغّل الصفحة مع ملفات GLTF المرتبطة من مسار مستضاف محليًا.
- لا يحتوي المشروع على مفتاح API. يجب توفير مفتاحك بنفسك.
